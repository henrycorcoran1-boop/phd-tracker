# AWDS Timeline of Change and Team KPI Summary

Client deliverable for MetroLink (AtkinsRéalis AWDS team). It carries MetroLink
branding on purpose and sits outside the Arya Estimating site; the house-style
skill does not apply here.

- `timeline-of-change.html` — the document, self-contained (fonts and logo embedded). Front page: package evolution and percentage increase; page two: timeline; then the key Delivery KPI, five supporting KPIs with commentary, a delivery and responsiveness evidence page, and Appendices A to C. Open in a browser; print to PDF at A4 landscape.
- `timeline-of-change.pdf` — the same document exported from Chromium.
- `build.py` — generates the HTML from the event data at the top of the file. Edit the data, run `python3 build.py`, and the diagram, KPI counts and appendices update together. Standard library only.
- `metrolink-mlogo.png`, `fonts/` — assets embedded by the build.

Source: AWDS Timeline of Change record, 15 September 2026.
