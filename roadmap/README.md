# Doctoral Programme Roadmap

Source for `build/Corcoran_PhD_Roadmap_RevB.pdf`, the standing execution context
for the doctoral programme on organisational culture, innovation readiness and
artificial intelligence readiness in construction project environments.

## Build

```
npm install playwright @fontsource/literata @fontsource/inter   # first time only
python3 maketoc.py                # regenerate contents and the figure/table lists
node build.mjs                    # render to PDF
python3 tocmap.py                 # resolve contents page numbers from the render
node build.mjs                    # render again, with the page numbers in place
```

`PLAYWRIGHT_BROWSERS_PATH` must point at an installed Chromium. The fonts in
`fonts/` are inlined into the document at build time, so the PDF renders
identically anywhere and needs no network access.

## Checking the output

```
python3 proof.py [first] [last]   # rasterise pages to build/proof/ for inspection
```

## Layout of the sources

| Path | Contents |
|---|---|
| `src/style.css` | House style, matching Corcoran_PhD_DraftClean_v05 |
| `src/00-cover.html` | Cover |
| `src/01-frontmatter.html` | Contents, figure and table lists, reading instructions |
| `src/01b-atglance.html` | The programme on one page, and the traceability matrix |
| `src/02` to `src/04a` | Parts One and Two: restructure, architecture, theory, design parameters |
| `src/05` to `src/09` | Part Three: the five workstreams |
| `src/10-control.html` | Part Four: sequencing, risk, ethics, prohibitions |
| `src/11`, `src/12`, `src/12b` | Appendices A to G |

The contents, the figure list and the table list are generated by `maketoc.py`
between marker comments in `01-frontmatter.html`. Edit the sources, not the
generated blocks.

## Conventions

British English throughout. `Section` refers to this roadmap; `Chapter` refers
to the thesis. Every analytical threshold appears in Appendix F and nowhere
else. References in Appendix G are single-pass verified and must be confirmed
against the publisher record before entering a manuscript.
