Shared delivery services

Drawn from a single resource pool and tasked into packages by the Design Manager. These roles are not embedded in any one contract team, which is the distinction the chart above is built to show.

Functional lines

The same people, regrouped by discipline. Every card names the contract that person sits under, which is what makes this a matrix rather than a second hierarchy.

How to read this chart

  • Solid connectors carry line management. A Package Delivery Lead answers to the Design Manager for cost, programme and deliverable acceptance.
  • Dashed rails carry functional authority. A Technical Manager takes technical direction and design assurance from the Technical Director; a Procurement Manager takes commercial governance from the Head of Procurement and Commercial.
  • Each contract team therefore has one operational reporting line and one functional line. Neither substitutes for the other, and a dispute between them escalates to the Design Manager.
  • The dotted client link is a contractual interface, not a reporting line. TII package sponsors instruct through the Project Director.
